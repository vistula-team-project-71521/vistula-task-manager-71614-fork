# Task Manager

A simple web application for managing tasks.

**Student ID:** 71614

**Course:** Team Project – IT

## Technologies

- HTML, CSS, JavaScript
- Supabase PostgreSQL
- Supabase REST API
- GitHub Pages

## Features

- View tasks
- Add new tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete tasks

All tasks are stored in a Supabase database.
